# 版本变更日志

这个项目的所有关键变化都将记录在此文件中.

此日志格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/),
并且此项目遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/).

## [Unreleased]

## [0.0.7] - 2026-04-16

### Added

- 标签墙支持配置自定义字体颜色组

### Changed

- 合并项目util
- 更新标签墙文档
- 实时时间添加多语言

### Fixed

- 修复标签墙插件未配置指定部件参数时导致初次加载数据异常
- 修复搜索栏未配置图片时搜索框样式异常
- 修复自定义边框8边框样式导致轮播列表项间隔样式异常
- 修复svg、rect图标高度报错

## [0.0.3] - 2024-08-23

### Added

- 新增标签墙支持字体大小参数

### Fixed

- 修复大屏数据看板插件异常

## [0.0.2] - 2024-08-21

### Added

- 新增门户实时时间插件，标签墙插件
- 补充门户实时时间文档，标签墙文档
- 大屏数据看板支持大屏模式
- 大屏门户支持内容区背景图
- 大屏搜索框搜索时抛出事件

## [0.0.1] - 2024-08-16

### Added

- 新增翻牌器插件，大屏数据看板插件，大屏门户插件，大屏时间插件，大屏日期选择插件，大屏单选循环插件，大屏面板容器插件，轮播列表插件，轮播表格插件，大屏进度条插件，面板按钮，进度池插件，水位图插件，装饰器1-6
- 补充插件文档

## [0.0.0] - 2024-05-21

初始化
